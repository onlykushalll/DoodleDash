# Security Policy

We take the security and integrity of Doodle Dash seriously. If you identify any potential security vulnerabilities, we appreciate your help in reporting them to us responsibly.

## Supported Versions

Only the latest release version on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v0.2.x  | :white_check_mark: |
| < v0.2  | :x:                |

## Reporting a Vulnerability

Please **do not** open public GitHub issues for security vulnerabilities. Instead, report them privately:

1. Send an email to the project maintainers (or open a private security draft on GitHub if enabled).
2. Detail the issue, including steps to reproduce, potential impact, and any proof-of-concept code or scripts.
3. Allow us reasonable time to investigate the report and publish a patch before disclosing the vulnerability publicly.

We will acknowledge your report within 48 hours and keep you updated as we work towards a resolution.

Thank you for helping keep Doodle Dash secure for everyone! 🔒
